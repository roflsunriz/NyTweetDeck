# AGENTS.md 完了監査

この文書は、実装量ではなく利用者が観測できる要件ごとに完成証拠を管理します。秘密情報や実アカウント操作を必要とする項目は、モック合格と実地確認を区別します。

## 目的・実行形態

| 要件 | 状態 | 証拠 |
| --- | --- | --- |
| Javaアプリを専用ローカルアドレスで開く | 検証済み | パッケージ済みJARを`127.0.0.1:18080`で起動しChrome検証 |
| Bun bundlerを使用する | 検証済み | Maven `generate-resources`と`frontend/scripts/build.ts` |
| Android版Xとして通信する | 実装済み・実地未検証 | バージョン付きAPIプロファイル、Androidヘッダー、端末プロファイル、OAuth 1.0a。実通信は資格情報の明示承認待ち |

## アカウント

| 要件 | 状態 | 証拠 |
| --- | --- | --- |
| Xへログイン | 実装済み・実地未検証 | Guest認証、動的OCF UI、`open_account`解析、OAuth資格情報のVault保存。実アカウント未実行 |
| ログイン状態を維持 | 検証済み（暗号化保存） | PBKDF2-HMAC-SHA256 + AES-256-GCM Vault、再解除テスト |

| Vaultロック時に通信を停止 | 検証済み | ロックイベントで秘密配列消去、Live Pipeline全切断、UI選択解除 |
